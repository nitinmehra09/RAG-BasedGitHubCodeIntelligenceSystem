How it works

The RAG pipeline, in motion

01

GitHub Sync

OAuth login, pick repos, fetch entire file tree via API.

02

Chunk & Parse

Code-aware chunking preserves functions & context boundaries.

03

Embed

04

Retrieve

Cosine similarity finds top-5 relevant chunks in ms.

05
